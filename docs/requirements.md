# MP3タイトル編集アプリケーション 要件定義

## 1. アプリケーションの概要

選択したフォルダ内のMP3ファイルからタイトルとアルバム名を読み取り、一覧で表示・編集するデスクトップアプリケーション。編集した値は一括適用によってファイルに反映できる。一括再取得によって、一覧の値をファイルに現在保存されている値に戻せる。

## 2. 開発の目的

複数のMP3ファイルのタイトルとアルバム名をひとつの一覧で確認・編集し、ユーザーが適用を選んだ時点で変更をまとめて反映できるようにする。

## 3. 想定ユーザー

Windows 11で、フォルダ単位でMP3のタイトルやアルバム名を整理したいユーザー。

## 4. 機能要件

### フォルダ選択と一覧表示

- 選択したフォルダの直下にある全MP3を対象とする。サブフォルダは対象外とする。
- 各ファイルからタイトルとアルバム名を読み取り、一覧に表示する。未設定の項目は空欄で表示する。

### 編集と未適用の判定

- 一覧でタイトルとアルバム名を編集できる。編集操作だけではファイルに書き込まない。
- アプリ内の値を、最後に読み取りまたは適用に成功した時点の値と比較する。いずれかの項目が異なるファイルを未適用とする。手入力で基準値に戻った項目は差分として扱わない。
- 一括再取得に失敗したファイルは、値の差分にかかわらず未適用として扱う。

### 一括適用

- 一覧を対象に、アプリ内の値が基準値と異なる項目だけを書き込む。タイトルだけが異なる場合は、タイトルだけを書き込む。
- 編集によって空欄にした項目は、適用時にファイルからその項目の値を削除する。

### 一括再取得

- 一覧の各MP3から、現在保存されているタイトルとアルバム名を読み直し、読み取りに成功したファイルのアプリ内の値を上書きする。
- 未適用の編集があっても確認を表示せず、ファイルには書き込まない。

### フォルダ切り替えと終了

- 未適用のファイルがある場合は、編集を破棄して操作を続行するか、操作をキャンセルして編集に戻るかを確認する。
- 確認の要否は最後に読み取りまたは適用に成功した時点の値と再取得の失敗状態に基づいて判定する。切り替えや終了の直前に判定のための再読み取りは行わない。

### ファイル単位のエラー処理

- 一部のファイルで読み取りまたは書き込みに失敗しても、他のファイルの処理を続ける。処理後に、失敗したファイル名と理由を表示する。
- 一括適用または一括再取得に失敗したファイルでは、アプリ内の編集中の値を保持する。

## 5. 非機能要件

- 利用環境はWindows 11を想定する。
- Windows固有の実装への依存は可能な限り抑える。
- 1フォルダあたり最大100件程度のMP3を想定する。

**未確定**　処理時間の数値目標と、Windows 11以外の対応範囲は未定。

## 6. 制約条件

- Pythonでデスクトップアプリケーションを開発する。
- ファイルに対する編集対象は、MP3のタイトルとアルバム名に限る。
- 適用と再取得は、いずれも一覧全体を対象とする一括操作とする。

## 7. 対象外の機能

- サブフォルダの検索と、MP3以外の形式の処理。
- タイトルとアルバム名以外のタグの編集。
- 選択したファイルだけへの適用や再取得。
- 適用済みのファイルを、適用前の値に復元する機能。

## 8. 完成条件

以下の動作をWindows 11で確認できること。

- フォルダ直下のMP3が一覧に表示され、サブフォルダ内のMP3は表示されない。未設定のタイトルやアルバム名は空欄になる。
- 一覧で編集しても適用前はファイルの値が変わらず、一括適用すると基準値と異なる項目だけが更新される。空欄に変更した項目の値は削除される。
- 一括再取得を実行すると、確認なしで現在のファイルの値が一覧に反映される。ファイルの値は変わらない。
- 再取得に成功しているファイルで、編集した値を手入力で基準値に戻すと、その項目は未適用と判定されない。
- 未適用のファイルがある場合、フォルダ切り替えと終了の両方で確認が表示される。操作をキャンセルした場合は、編集中の値が保持される。未適用のファイルがない場合は、この確認を表示しない。
- 一部のファイルで処理に失敗しても他のファイルの処理を続け、終了後に失敗したファイル名と理由を表示する。適用または再取得に失敗したファイルの編集中の値は保持され、再取得に失敗したファイルは未適用と判定される。
- MP3が100件程度あるフォルダで、一覧表示、編集、一括適用、一括再取得を行える。
